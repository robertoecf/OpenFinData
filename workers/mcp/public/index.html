Dados Financeiros Abertos · alpha

MCP público no Cloudflare Workers

Superfície pública: /mcp (Streamable HTTP). REST/FastAPI, CLI e code mode não ficam na internet — só na rede Tailscale.

Uso justo: cerca de 60 req/min por IP (pico 20 / 10s). Sem API key. Sem execução de código no endpoint público. Excesso em /mcp responde 429 + Retry-After.

Tools neste Worker (fontes públicas, sem processar Python):

  • bcb_series bcb_ptax bcb_focus
  • ibge_indicator ibge_ipca_breakdown
  • ipea_series ipea_search
  • tesouro_siconfi
  • openfinance_directory
  • cvm_fund — cadastro RCVM 175, cotas INF_DIARIO e carteira CDA

B3/ANBIMA/registry, lâmina/perfil e a API REST completa continuam no pacote Python (pip install openfindata) e no FastAPI interno.

Cliente MCP:

{
  "mcpServers": {
    "openfindata": {
      "url": "https://openfindata.com.br/mcp"
    }
  }
}
