O que dá para perguntar

Exemplos reais, respondidos com dado oficial. Você escreve assim mesmo, em linguagem natural, dentro do seu assistente.

"Como a Selic evoluiu nos últimos 12 meses?" bcb_series, série 432 do SGS do Banco Central
"O que o Boletim Focus projeta para o IPCA de 2027?" bcb_focus, expectativas de mercado coletadas pelo BCB
"Qual foi a inflação por grupo no último IPCA? O que puxou para cima?" ibge_ipca_breakdown, abertura que não existe no SGS
"Mostre a carteira mais recente do fundo com CNPJ 21.624.757/0001-26." cvm_fund, informe de composição de carteira (CDA) da CVM
"Quais municípios do Mato Grosso aparecem no SICONFI e qual a população deles?" tesouro_siconfi, dados de finanças públicas do Tesouro Nacional

Como conectar em um minuto

Este serviço fala MCP (Model Context Protocol), o padrão aberto que permite a um assistente de IA consultar uma fonte de dados externa com segurança. Na prática: você cola um endereço na configuração do seu assistente e ele ganha acesso às ferramentas listadas abaixo.

Claude Desktop, Claude Code, Cursor e similares

{
  "mcpServers": {
    "openfindata": {
      "url": "https://openfindata.com.br/mcp"
    }
  }
}

Em clientes que pedem só a URL, use https://openfindata.com.br/mcp e escolha o transporte Streamable HTTP. Não há etapa de login.

O que este serviço não faz

  • Não calcula indicador derivado. Sem Sharpe, sem CAGR, sem drawdown. Ele entrega o número que o órgão publicou, normalizado, e a conta fica com você ou com o seu assistente.
  • Não acessa dado de cliente. O Open Finance aqui é só o diretório público de participantes, nunca informação de conta de ninguém.
  • Não revende dado de terceiros nem executa código no endpoint público.
  • Não é recomendação de investimento.

Limites e transparência

  • Uso justo: cerca de 60 requisições por minuto por IP, com pico de 20 a cada 10 segundos. O excesso recebe HTTP 429 com Retry-After.
  • Resposta longa vem paginada, com total_matched, returned e truncated. Se truncated for verdadeiro, você não viu tudo.
  • Parâmetro desconhecido é recusado com erro explícito, nunca ignorado em silêncio.
  • Lista vazia não é erro: quando cabe, um campo reason explica o motivo, como PTAX ainda não publicado no dia ou fim de semana.
  • Projeto em alpha. A superfície pode mudar, e o repositório é a fonte da verdade.

Para quem desenvolve

O endpoint público é só o MCP. A biblioteca Python, a API REST em FastAPI, a CLI e as fontes adicionais (B3, ANBIMA, SUSEP, ANEEL, Receita Federal e o registro de CNPJ e ticker) ficam no repositório e rodam localmente. Instruções de instalação, contribuição e a matriz completa de fontes estão no GitHub. Resumo legível por máquina em /llms.txt.
